# Dados coletados pelo aplicativo

O aplicativo Loja Verde facilita o dia a dia de compras, como acompanhar pedidos, usar vales-compras e pedir trocas. Para isso, ele coleta alguns dados e pede algumas permissões no celular. Este documento explica quais são essas informações, por que elas são necessárias e como você pode controlar as permissões. A linguagem é simples para que você entenda cada ponto.

## Dados de cadastro

Quando você cria uma conta, pedimos nome, e-mail, telefone e CPF, além de endereços de entrega. Esses dados identificam você nas compras, permitem o contato sobre pedidos e são necessários para emitir a nota fiscal. A senha é guardada de forma protegida, e a equipe da Loja Verde não tem acesso à senha em texto.

## Dados de uso do aplicativo

Registramos informações como telas acessadas, produtos vistos, buscas feitas e tipo de aparelho. Esses dados ajudam a melhorar a navegação e a corrigir falhas. Eles não são usados para identificar você fora da conta.

## Permissão de localização

A localização é usada em duas situações. Quando você pede para ver as unidades mais próximas, o aplicativo usa a posição do aparelho para mostrar a loja mais perto. Também pode ser usada para sugerir o endereço de entrega, desde que você confirme. Se você não quiser compartilhar a localização, pode informar um endereço manualmente, e o aplicativo continua funcionando.

Exemplo: uma cliente abre o aplicativo para retirar um pedido na unidade mais próxima. Ela permite a localização só durante o uso, e o aplicativo mostra a loja de Contagem ou de Betim, conforme a posição.

## Permissão de câmera

A câmera é usada para ler códigos de barras, cupons e o código do vale-compras, e também para enviar fotos de produtos com defeito ao pedir uma troca. A câmera só é ativada quando você usa essas funções. Não usamos a câmera para registrar imagens em segundo plano.

## Notificações

Com a permissão de notificações, você recebe avisos sobre o status do pedido, a saída para entrega e a disponibilidade de vales. Se preferir, pode desativar as notificações de promoções, mantendo apenas as notificações de pedidos.

## Como gerenciar as permissões

No celular, vá até as configurações do aparelho, abra a lista de aplicativos, escolha Loja Verde e ajuste as permissões de localização, câmera e notificações. No aplicativo, a área de Privacidade também mostra as permissões ativas.

## Dúvidas e direitos

Você pode pedir acesso, correção ou exclusão dos dados coletados pelo aplicativo. Para isso, escreva para privacidade@lojaverde.example. A resposta chega em até 15 dias. Para dúvidas gerais, o SAC atende pelo número 0800 700 0100.
