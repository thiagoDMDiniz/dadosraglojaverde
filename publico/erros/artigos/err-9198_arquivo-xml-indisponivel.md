# Como resolver o erro ERR-9198: arquivo XML indisponível

Quando você tenta baixar o arquivo XML da nota fiscal e recebe a mensagem ERR-9198, o documento existe, mas não pode ser entregue naquele momento. Este artigo mostra como localizar o arquivo e o que fazer quando ele não aparece.

## O que significa

O código ERR-9198 indica que o arquivo XML da nota fiscal não está acessível para download. O XML é a versão eletrônica do documento, usada por contadores e sistemas de gestão. Enquanto ele não estiver disponível, o download fica bloqueado, mas a compra e o registro fiscal não são afetados.

## Por que acontece

O arquivo pode ficar indisponível por motivos como:

- a transmissão do documento ao órgão fiscal ainda não foi concluída;
- o arquivo foi gerado, mas ainda está em processamento no servidor;
- a conexão com o serviço de armazenamento de documentos foi interrompida;
- o pedido teve alteração recente, o que gera uma nova versão do XML.

Na maioria dos casos, a indisponibilidade é temporária e o arquivo fica pronto em seguida.

## Como resolver

1. Abra o aplicativo Loja Verde e acesse Meus Pedidos.
2. Localize o pedido e abra a seção de documentos fiscais.
3. Tente baixar o XML novamente depois de alguns minutos, sem atualizar a página várias vezes em sequência.
4. Verifique se existe um PDF da nota disponível, que pode ser usado enquanto o XML não aparece.
5. Se o arquivo continuar indisponível, procure o SAC com o número do pedido.

## Quando procurar o SAC

Fale com o SAC pelo 0800 700 0100 (segunda a sexta, das 8h às 20h, e sábados, das 8h às 14h) se o ERR-9198 aparecer por mais de um dia útil, ou se você precisar do XML para lançamento contábil. Informe o número do pedido e o CNPJ ou CPF da nota. Também é possível escrever para atendimento@lojaverde.example.

## Dicas para evitar

- Baixe o XML logo que ele estiver disponível e guarde uma cópia em local seguro.
- Use uma conexão estável ao fazer o download de arquivos fiscais.
- Organize os arquivos por número de pedido, para facilitar a conferência mensal.
