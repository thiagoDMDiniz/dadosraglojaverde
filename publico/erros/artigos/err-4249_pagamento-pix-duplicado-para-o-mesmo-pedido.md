# Como resolver o erro ERR-4249: pagamento Pix duplicado para o mesmo pedido

## O que significa

O erro ERR-4249 aparece quando o sistema identifica dois pagamentos Pix recebidos para um mesmo pedido. Isso significa que o valor foi transferido mais de uma vez, seja porque o cliente pagou duas vezes, seja porque dois códigos foram gerados e ambos foram quitados. O pedido só pode ser considerado pago uma vez, então o excedente precisa ser identificado e devolvido. O código pertence à família Pagamento por Pix e não cancela o pedido original.

## Por que acontece

A duplicidade quase sempre nasce de uma ação repetida. O cliente gera um novo código Pix porque a tela demorou a atualizar, e depois paga os dois. Outra origem comum é clicar várias vezes no botão de pagamento, ou reabrir o pedido em outro dispositivo e gerar uma segunda cobrança. Em alguns casos, a confirmação do primeiro pagamento chegou com atraso, e o cliente pagou de novo achando que o anterior não tinha dado certo.

## Como resolver

1. Abra Meus Pedidos e confirme se o pedido aparece como pago, pois a primeira transferência geralmente já foi aceita.
2. Verifique no extrato do seu banco quantas transferências foram feitas para a Loja Verde nesse período.
3. Não faça um terceiro pagamento para tentar resolver o problema.
4. Entre em contato com o SAC e informe o código ERR-4249, o número do pedido e os comprovantes das duas transferências.
5. Aguarde a análise. O valor excedente será devolvido pela mesma forma de pagamento, dentro do prazo de reembolso previsto.

## Quando procurar o SAC

Procure o SAC assim que o código ERR-4249 aparecer e você notar que pagou duas vezes. Quanto antes o comprovante for enviado, mais rápida será a conferência. O atendimento funciona de segunda a sexta, das 8h às 20h, e aos sábados, das 8h às 14h, pelo telefone 0800 700 0100. Também é possível escrever para atendimento@lojaverde.example, anexando os comprovantes em formato legível.

## Dicas para evitar

- Aguarde a confirmação do pagamento antes de gerar outro código.
- Clique uma única vez no botão de pagamento e espere a tela atualizar.
- Não abra o mesmo pedido em dois aparelhos ao mesmo tempo para pagar.
- Guarde todos os comprovantes de transferência até o status do pedido mudar para pago.
- Se a tela parecer travada, atualize o aplicativo antes de tentar novamente.
